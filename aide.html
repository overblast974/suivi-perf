🚀 Ouvrir l'application

📱 Accès depuis votre téléphone

  1. Assurez-vous d'être sur le même réseau WiFi
  2. Trouvez l'adresse IP de cet ordinateur :
    • Windows : ipconfig
    • Mac/Linux : ifconfig
  3. Sur votre téléphone, ouvrez le navigateur
  4. Tapez : http://IP_ADDRESS:8000
  5. Exemple : http://192.168.1.45:8000

🎯 Guide rapide

  1. Tableau de bord : Vue d'ensemble de vos entraînements
  2. Nouvel entraînement : Cliquez sur le bouton "+" pour ajouter une séance
  3. Choisissez le type : Musculation, Course, CrossFit ou Hyrox
  4. Remplissez les champs qui s'affichent automatiquement
  5. Enregistrez et consultez vos statistiques !

💾 Stockage des données

Toutes vos données sont stockées localement dans votre navigateur (IndexedDB). Aucune connexion internet n'est nécessaire après le premier chargement.
